Privacy Policy

Application: Zen Gmail Read Only · Effective date: October 6, 2026

1. About this application

Zen Gmail Read Only ("the Application") is a private, single-user software tool operated by JN Gonzales ("the Operator"). It is not a public product and is not offered, distributed, or made available to any users other than the Operator acting on their own Google Account.

2. What data the Application accesses

With the Operator's explicit consent, and limited to the Operator's own Google Account, the Application accesses Google user data through the Gmail API using the read-only scope (https://www.googleapis.com/auth/gmail.readonly). Specifically:

  • Email message metadata (sender, recipients, subject, date, message and thread identifiers).
  • Message content and attachments, only to the extent needed to locate and fetch attachments.

The Application never sends, deletes, modifies, labels, or otherwise alters any email. It performs no write operations of any kind on Google user data.

3. How data is used and stored

  • All processing happens locally on the Operator's personal device.
  • Fetched messages and attachments are stored in a local file archive on the Operator's device, for the Operator's own record-keeping and workflow.
  • OAuth credentials are stored locally on the same device and are never transmitted to any server controlled by the Operator.
  • No Google user data is uploaded to, processed by, or shared with any third-party server, service, or individual.

4. Data sharing

No data accessed through Google APIs is sold, rented, shared, transferred, or disclosed to any third party. There is no advertising, analytics, or tracking in the Application.

5. Retention and deletion

Locally archived data is retained on the Operator's device until the Operator deletes it. Access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions), which immediately invalidates the Application's tokens.

6. Google API Services User Data Policy

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Security

Access tokens and refresh tokens are stored locally in protected files on the Operator's device. No credentials are embedded in public code or shared with third parties.

8. Changes to this policy

Any changes to this policy will be published on this page with an updated effective date.
