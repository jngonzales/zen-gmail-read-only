Zen Gmail Read Only

A personal, single-user tool for archiving email attachments from the owner's own Gmail account.

Zen Gmail Read Only connects to the operator's own Gmail account using Google's official API with the read-only scope. It is used to fetch and file email attachments into a local file archive on the operator's own device, alongside related work documents.

  • Read-only access. It never sends, deletes, or modifies email.
  • Runs locally on the operator's device. Data is not uploaded to any third-party server.
  • Built and operated by JN Gonzales for personal workflow use only. It is not offered to the public.
